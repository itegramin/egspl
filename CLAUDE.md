### Quick Cheatsheet:
- **Build**: `npm run build`
- **Lint / Typecheck**: `npm run lint` (`tsc --noEmit`)
- **Dev**: `npm run dev`
- **Deployment**: Azure Static Web Apps via GitHub Actions (`base: '/'` in `vite.config.ts`)
- **Formatting**: Format currency with `src/lib/indianCurrency.ts`
